## 3. 标注与裁决
1. **Claude 第一标注：** 全部条目都标，看不到抽取器输出。
2. **GPT 盲标：** 测试集中分层随机抽 120 条；之后再从这 120 条里抽 20 条，由 Owner 盲标抽查。
3. **一致性计算：**
   - κ：以帖子级 (record_id, symbol) 为单位，在同一批 120 条上计算两位标注者对“是否为观点”的 Cohen's κ，同时报告混淆矩阵、各类别比例和观察一致率。
   - 方向一致率：只在双方都给出方向的条目上计算，并报告分母。ambiguous 和 unavailable 单独计数。
4. **冻结门槛：** κ ≥ 0.60、方向一致率 ≥ 0.85，且 Owner 抽查 20 条中不一致的不超过 3 条。达不到门槛时，修订指南到 v1.3，并换一批新样本。
5. **裁决：** 所有分歧都保留原始标签和理由，由 Owner 最终裁决，Claude 不裁决自己参与的分歧。只有 Claude 一人标过的条目，如实写为“单人标注 + 已测一致性”。
6. 测试集冻结后不再改动；开发集的裁决只追加记录。

## 4. 打分与报告
- 以帖子为单位：观点按 (record_id, symbol, 粗方向) 去重后再计算 P / R。条目级结果只用于诊断。
- 报告 P、R、弃权率、正确弃权数、可追溯率，每项都带分母和 Wilson 区间，并附按帖子聚类的 bootstrap 区间。
- 结果分别按渠道、作者、持有人报告；某层观点数不足时标为 INSUFFICIENT。同时给出测试集的实际构成。
- 过关线：R ≥ 0.60、P ≥ 0.85、观点 ≥ 100、预测 ≥ 50。点估计过线但区间不稳时，写“过线（区间未稳）”。
- 第一个评估对象固定为生产版 ce-4。每个版本只评估一次；同一测试集最多评估 3 个版本，之后启用 v5。
