# myAlphaView V2.6 可靠性升级

本版不改变 `CORE_TIERS`、资金分档、VIX 仪表盘、Alpaca Indicative 口径和 100 倍期权乘数。

## 已完成

- 修正市场状态引擎的回撤误报：回撤项只按自身 `-8%` 阈值判断。
- 期权缓存报价增加新鲜度：30 分钟内新鲜、30–90 分钟延迟、超过 90 分钟过期。
- 过期报价仍可作为历史参考，但不计入行情覆盖率，也不作为可靠风控报价。
- 构建前增加数据质量门；未通过时停止覆盖上一版站点。
- `data.json` 和 `index.html` 使用临时文件完成后再替换，减少半写入文件风险。
- 增加 `stock_targets` 的数据库行级权限迁移。

## 首次更新时需要额外执行一次

在 Supabase SQL Editor 中执行：

`supabase/migrations/202609220001_stock_targets_private.sql`

这一步只需执行一次。它不会修改现有目标价，只限制目标价的写入权限。

## 页面可见变化

- 当前 `-0.67%` 左右的指数回撤会显示“未触发”，2 分正确归属于 20 日市场宽度。
- 期权持仓最新价下方会显示“新鲜 / 延迟 / 已过期”。
- 超过 90 分钟的缓存报价会触发“报价已过期 · 请刷新”风险提示。

## 回退

如需回退，重新上传并部署升级前的完整压缩包即可；本版没有删除或重命名现有数据库字段。
