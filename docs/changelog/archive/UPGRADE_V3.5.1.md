# myAlphaView V3.5.1 数据状态中心修正

## 本次更新

- 修复 GitHub Actions 仍检查已删除 `strategy-budget.js`、导致未来完整部署后每日任务无法提交的问题。
- 删除场外基金接口、相关抓取代码与页面状态项。
- 数据状态中心改为全中文、紧凑的五项健康状态卡，补充更新频率和降级说明。
- 市场宽度根据最近已完成的美股交易日自动判断“已更新 / 最近有效收盘 / 数据陈旧”。
- 美股盘中刷新统一为每 5 分钟，休市每 15 分钟检查，避免不必要的接口消耗。
- 亚太行情来源统一显示为“腾讯行情”。

## 部署后操作

上传完整目录后，在 GitHub Actions 手动运行一次 `Daily Dashboard Update`，使 `docs/data.json` 和 `docs/index.html` 使用最新完整收盘数据重新生成。
