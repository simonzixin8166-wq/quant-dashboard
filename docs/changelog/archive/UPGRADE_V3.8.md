# V3.8.0 更新说明：TQQQ X2 与 LEAPS 机会雷达

本版新增的是“机会提示系统”，不是下单系统，也不计算投入金额或合约数量。

## TQQQ X2 收盘状态机

- X2 的含义固定为目标约 2 倍日内敞口，对应页面目标档位 `0% / 33% / 67% TQQQ`。
- 当前实际记录固定显示为空仓，避免把策略目标误认为真实持仓。
- 规则优先级固定为：硬退出 → 二级降险 → 一级降险 → 恢复。
- 没有新信号时延续上一收盘状态，不会自动跳回满仓。
- 所有正式结论使用完整收盘日线，次日执行；盘中数据不改变正式状态。
- 页面保留最近 20 个交易日状态，并将重要降险结论放入“今日风险待办”。

## 默认规则

- 一级降险：VIX 三日涨幅 >20%、VIX≥18、QQQ 低于 MA20，目标不高于 33%。
- 二级降险：VIX 三日涨幅 >20%、VIX≥20，且 QQQ 低于 MA50 0.5% 或连续两日低于 MA50，目标 0%。
- 硬退出：VIX>26 且 QQQ<MA50，或 QQQ<MA200 且 VIX>24，目标 0%。
- 超卖恢复：RSI≤30、硬退出已解除且 VIX≤26，恢复至 33%。
- 趋势恢复：连续两日站上上升 MA20 且 VIX 三日涨幅≤20%，至少恢复至 33%。
- 完整恢复：同时站上 MA50、MA20 上升且 VIX<20，恢复至 67%。

## LEAPS Call 机会雷达

- 标的：QQQ、SMH、VGT。
- 观察：RSI≤40 或从 63 日高点回撤≥5%。
- 候选：RSI≤35 且回撤≥8%。
- 强候选：RSI 连续两个收盘≤30 且回撤≥10%。
- 风险纪律：单次权利金风险上限 1%，全部 LEAPS 合计上限 3%；仅显示比例，不推导金额。
- 成长型合约：DTE 365–900 天，Delta 0.50–0.60。
- 替代正股合约：DTE 540–900 天，Delta 0.70–0.85。
- 仅保留有效 Bid/Ask 且相对价差≤15%的候选；≤10%优先。
- 候选链登录后按需读取现有 Alpaca Indicative 接口，下单前仍以 IBKR Bid/Ask 为准。

## 站内提醒与记录

- TQQQ 的 0%/33%降险状态，以及 LEAPS 候选/强候选，会进入首页“今日风险待办”。
- 生成器保留有意义的收盘机会历史，按日期、模块、标的和级别去重。
- 不增加外部定时任务、不发送邮件或短信、不自动下单。
