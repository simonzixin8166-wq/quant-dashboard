# V4.0.0 · PWA 第二阶段移动端界面

- 电脑端继续保留原来的固定侧边栏和宽屏工作台。
- 手机端隐藏桌面侧栏，改为“总览、策略、观察、期权、更多”底部主导航。
- “更多”使用底部抽屉集中显示全部模块、主题、安装和登录入口。
- 手机顶部栏压缩为应用名称、当前模块和数据日期，不再占用大面积屏幕。
- 市场指标改为手机双列卡片，VIX单独占整行；超窄屏自动改单列。
- 期权开放持仓表在手机上转换为分账户卡片，盈亏、Delta、风险和操作不再依赖横向表格。
- 观察池沿用手机卡片；其它复杂表格保留横向滑动并明确提示。
- 工具栏、筛选器、按钮和表单扩大触控区域，兼容底部安全区域。
- 更新 Service Worker 缓存为 V4.0.0，已安装PWA会提示立即更新。
