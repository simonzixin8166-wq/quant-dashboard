# V4.5.3 — Website-only + Plain-language Trend Pulse

- 删除 PWA / APP 安装、manifest、service worker、离线页和安装提示。
- 保留响应式手机网页与手机底部导航。

- 明确：高分不等于追高；减仓/退出需要负区 + 动能下降 + 中期转空等组合条件。
