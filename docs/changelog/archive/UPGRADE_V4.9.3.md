# V4.9.3 BrightLine 方法地图与针对性升级

目标不是复制 BrightLine 的持仓比例或交易结论，而是把公开文章中反复出现的思路拆成可验证的研究流程，并映射到 myAlphaView 已有模块。

## 新增
- 文学城新增“方法地图”：指数优先、Survival first、先 thesis 后杠杆、概率/期望值、持续验证、AI边界。
- 每条方法都显示：核心规则、适用边界、本站对应、下一步能力、来源链接。
- 投资知识新增“决策流程”：核心ETF → 个股thesis → 趋势确认 → 杠杆检查 → 复盘。
- 方法库增加本站差距矩阵，明确哪些已采用、哪些只部分实现、哪些仍需验证。
- 入仓检查强化 thesis、催化剂、失效条件、事件和杠杆风险，不记录账户金额。

## 不做
- 不自动改变 QQQM/VGT/QLD 回撤阈值。
- 不把 BrightLine 个人仓位比例复制为用户规则。
- 不把 Trend Pulse 改成单独买卖信号。
- 不把公开博文观点视为事实；仍保留来源与待核验层。
