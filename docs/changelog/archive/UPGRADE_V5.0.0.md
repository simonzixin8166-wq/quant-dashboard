# V5.0.0 · Investment Assistant Engine

## 本版目标
把网站从“指标看板”继续推进为面向普通投资者的研究助手。

## 主要变化
- Trend Pulse 改为两层表达：**分数区间 = 位置**，**动态阶段 = 方向**。
- 首页新增盘中期权研究提醒：美股指数/ VIX 每次 5 分钟刷新后重新判断。
- 恐慌/大跌阶段给出 Sell Put、Buy Call、LEAPS Call 的研究入口；强势加速阶段给出 Covered Call / Protective Put 的风险管理入口。
- Sell Put 经验参数保留为**待验证初筛**：Delta 0.16–0.20、30–45 DTE，不宣称为普遍最优。
- LEAPS Call 作为 12–24 个月以上的中长期研究候选，优先用于 QQQ 或 Thesis 清楚的个股；不写死单一 Delta。
- 关注池候选会自动避开明显“趋势恶化 / 趋势退潮”，并提示仍需人工检查 Thesis、财报/事件和最大风险。
- “文学城”升级为“方法研究中心”：自动采集技术错误折叠到后台状态，已沉淀方法、具体操作和人工提供的链接/正文继续可用。
- 方法研究中心新增“策略经验库”，用于汇总自有经验和后续博主策略，并保留来源、条件、边界和风险。
- Footer 匿名访问统计改为纯文字，直接并入版权区域，不再形成独立方框。
- 菜单“策略推演沙盒”改名为“期权决策与推演”。

## 首页期权提醒初始研究阈值
这些阈值只用于提醒研究，不自动下单，后续应通过历史样本验证：
- 观察：NASDAQ <= -1.5% / S&P 500 <= -1.25% / VIX >= 25
- 大跌：NASDAQ <= -2.5% / S&P 500 <= -2.0% / VIX >= 28
- 极端：NASDAQ <= -4.0% / S&P 500 <= -3.5% / VIX >= 35

## 未改变
- QQQM / VGT / QLD 等核心 ETF 回撤阈值。
- Trend Pulse 计算公式本身。
- 期权 Black-Scholes / 情景推演数学。
- Supabase 真实持仓与 RLS 结构。

## 设计原则
提醒是“研究候选”，不是“买入/卖出命令”。先解释为什么、适用条件、不适用条件和最大风险，再允许进入专业参数。
