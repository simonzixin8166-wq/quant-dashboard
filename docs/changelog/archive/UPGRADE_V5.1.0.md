# V5.1.0 · Autonomous Investment Assistant

本版把 V5.0 的首页期权提醒扩展为持续值守的投资分析助手。核心原则：自动发现、解释、排序和复盘；不自动下单，不允许 AI 自行修改核心 ETF 阈值。

## 主要升级

1. **全站 Rule Registry**：统一登记市场、Trend Pulse、个股 Thesis、期权经验和数据完整性规则，并标明 Agent / 模块 / 状态 / 触发条件 / 动作。
2. **Market Agent**：沿用盘中 5 分钟指数刷新，自动识别观察 / 大跌 / 极端环境：NASDAQ -1.5/-2.5/-4.0%，S&P 500 -1.25/-2.0/-3.5%，VIX 25/28/35。
3. **Stock Agent**：触发后自动扫描登录用户观察池；Thesis 缺失、趋势退潮/恶化会降级，二次启动/修复会提高研究优先级。
4. **Options Agent**：登录且已有 Alpaca 行情权限时，对前 3 个候选自动读取期权链。Sell Put 使用既有经验区间 30–45 DTE / |Delta| 0.16–0.20 做初筛；LEAPS 只比较 365–760 DTE 的长期合约并强调 Delta~0.70 只是用于可比样本，不是固定规则；Buy Call 仅在启动/二次启动状态生成比较候选。
5. **Risk Agent**：规则冲突时风险优先；没有 Thesis、趋势明显恶化、数据不可用时不把市场大跌机械转成交易信号。
6. **提醒降噪**：只有状态从正常→观察→大跌→极端，或高位风险状态发生变化时才弹 Toast；同一级别 5 分钟轮询不会重复提醒。
7. **自动 Decision Journal 雏形**：浏览器本地保存最近 120 个自动扫描事件，记录市场级别和候选代码，为 V5.2 的 20/60/120 日结果验证留接口。
8. **首页普通话输出**：显示 Market / Stock / Options / Risk 四个 Agent 的当前判断，随后给关注池候选、可研究策略和自动期权链初筛结果。

## 不变项

- QQQM / VGT / QLD 等核心 ETF 回撤阈值未改。
- Trend Pulse 算法未改，只改解释和联动。
- 不自动下单。
- 博主经验不能直接写入生产规则，仍需进入候选/验证流程。
- 公共页面不展示真实持仓金额、账户收益或成本。

## 自动化边界

网页打开时，`market-live.js` 在美股常规时段每 5 分钟自动拉取指数/VIX并触发 Agent，不需要手动刷新网页。个股观察池盘中约每 10 分钟刷新，期权持仓约每 15 分钟刷新。当前个性化观察池与期权链扫描依赖登录会话，因此浏览器关闭后不会在云端持续读取私人观察池；V5.2/后续如需 24×7 私人后台 Agent，应迁移为 Supabase 后台任务并保留 RLS。
