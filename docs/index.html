期权持仓监控清单

公开版暂不接入实时期权行情（免费数据源普遍不支持及时的期权Greeks），先提供持有期权期间需要重点盯防的指标清单，作为自查参考。

⏳ 剩余到期天数 (DTE)

越接近到期，时间价值(Theta)衰减越快，尤其是最后30天内加速明显。

🎯 距行权价的距离

标的价与行权价的百分比差距，判断合约是价内(ITM)、价平(ATM)还是价外(OTM)。

📈 隐含波动率 (IV) / IV Rank

IV突然飙升或回落会显著影响期权价格，尤其在财报、FOMC等事件前后。

Δ Delta

标的价每变动$1，期权价格大致的变动幅度，也约等于到期时处于价内的概率。

Θ Theta（时间价值衰减）

每天因时间流逝损失的权利金金额，临近到期会加速。

Γ Gamma

Delta本身的变化速度，临近到期或价平附近时Gamma风险最大。

💰 内在价值 vs 时间价值

内在价值 = 标的价与行权价的实际价差；剩余部分是时间价值，到期归零。

⚖️ 盈亏平衡价

买入认购：行权价+权利金；买入认沽：行权价-权利金，判断到期需要标的价到哪里才不亏。

📅 关键事件日历

财报日、除息日、宏观数据发布日，都可能造成标的价或IV的剧烈跳动。
